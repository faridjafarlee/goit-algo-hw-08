# Task 1: Мінімальні витрати на об’єднання кабелів

## Умова
Є декілька кабелів різної довжини. За один крок можна з’єднати **два** кабелі в один.  
**Вартість** одного з’єднання дорівнює **сумі довжин** двох кабелів.  
Потрібно знайти порядок з’єднань, який дає **мінімальні загальні витрати**.

## Ідея
Щоб мінімізувати суму, завжди вигідно з’єднувати **два найкоротші** кабелі першими.  
Для цього використовуємо **мін-купу**.

## Складність
- Час: `O(n log n)`
- Пам’ять: `O(n)`

## Реалізація
Функція:
- `min_cable_connection_cost(lengths) -> (total_cost, steps)`

Де:
- `total_cost` - мінімальні загальні витрати
- `steps` - список кроків `(a, b, a+b)` для наочності

## Запуск
python cable_connection.py


# Task 2 (опціонально): Merge k sorted lists через мін-купу

## Умова
Дано k відсортованих списків цілих чисел.
Потрібно об’єднати їх у один відсортований список, використовуючи мін-купу для ефективності.

## Ідея
- Кладемо в купу перший елемент кожного списку у вигляді:
`(value, list_index, element_index)`

- Далі:
дістаємо мінімум
додаємо його в результат
з того ж списку пушимо наступний елемент (якщо він існує)

## Складність
- Час: `O(N log k)`, де `N` - загальна кількість елементів у всіх списках
- Пам’ять: `O(k)` для купи (не рахуючи результат)

## Реалізація
Функція:
merge_k_lists(lists) -> merged_list

## Запуск
python merge_k_lists.py
